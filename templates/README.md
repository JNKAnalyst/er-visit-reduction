# Templates

CSV templates for the model's editable inputs. Replace illustrative defaults with project-specific values.

| File | Purpose |
|------|---------|
| `config_template.csv` | Scenario parameters (baseline visits, cost per visit, reductions) — pasted into the workbook's `Config` sheet |
| `baseline_visits_template.csv` | Monthly baseline ER utilization — pasted into the `Baseline` sheet |

The values shipped here are illustrative and intentionally do not reproduce proprietary HCE case data. Calibrate before running production analysis.
